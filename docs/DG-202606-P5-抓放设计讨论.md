## 1. P5 要解决什么

评测要的是：**看见当前 `kind` → 抓起 → 立刻送到配送桌 → 下一件**。P4 只把底盘送到货架接近点 / 配送接近点。P5 是手臂 + 夹爪 + 视觉锁目标 + 放货。

官方 `client_task_1.py` 只做到「夹住可乐后倒车，手里还握着」，**没有放桌**。不要把它改成评分主入口。新逻辑在 `runtime/`。

B 线完成标准（仍未打勾）：

- 用 `kele.pt` 完成至少 **1 次** 取可乐并放到配送桌（裁判认可或目视稳定）
- 超时与 `stop_all` 在异常时会停
- 评分入口可一键启动

当前策略：先稳定固定布局 `product_032` / `kele`，9 类权重到了再扩。不要为 9 类先写两套 Client。

## 3. 初版里已经暴露的问题

这些问题要先讨论再改，不要边讨论边扩 9 类。

### 3.1 整段是按「北向货架 + 可乐罐」写死的

官方 creep / retreat / `DEPLOY_OFFSET` / `CREEP_STOP_Y` 用的是**世界系 +Y（北）**，假设车朝北、货在更北的货架上。

- `CREEP_STOP_Y = object_y + 0.035`：只对北向货架有意义
- `DEPLOY_OFFSET = (-0.011, -0.220, -0.010)`：世界系平移，不是 footprint 系
- `RETREAT`：倒车直到 `y ≤ 2.475`
- `REACH_Z` 只收 `0.70–1.15 m`：覆盖 **L2**，L1（中心约 0.55）和 L3（约 1.22）会被丢掉

固定 `product_032`（D-L2 可乐）能用。换层、换朝向、换形状会坏。

### 3.2 视觉点是罐前表面，不是几何中心

`VISION_SURFACE_TO_CENTER_FWD = 0.0265` 就是可乐碰撞半径。深度在可见表面，再沿 footprint 前向补一个半径。

其它 `kind` 半径不同（见第 4 节）。用可乐半径去补苹果 / 纸巾 / 脉动，夹爪会偏。

P5 日志里视觉 `z=0.958`，MJCF 中心 `z=0.9235`，差约 3.5 cm，也符合「看到的是表面/偏上」。

### 3.3 夹爪闭合是为细可乐调的

`GRIP_CLOSE = 0.08` 是 **0～1 的张开指令**，不是米。对应两指内缘约 **6.4 mm**（见第 4.1 节），比可乐直径 53 mm 小很多，靠把物体挤在指面之间。纸巾盒最短边 85 mm 已经超过最大开口 80 mm，同一套闭合值不能直接套。

### 3.4 放货还没在仿真里证明

代码有 `PLACE_DEPLOY_Z=0.92` / `PLACE_LOWER_Z=0.85` / 松爪 / 后撤。桌面目标 z=0.807，裁判框 `delivery_box` z∈[0.74, 1.05]。

未回答：

- 夹着东西走 P4 时手臂还发不发位置（现在导航段不发臂）
- 放下后直立 ±15° 才有 upright 加分
- 搬离货架要水平 ≥0.20 m（`carry_out_dist`）
- 掉落 z 掉过 0.30 m 算 drop 罚分

`placed=true` 只表示 Client 动作走完，**不是** Server 裁判。

### 3.5 编排还没接到真运动

`MissionOrchestrator` 仍是「取一件必须送一件」的约束器。预览里若有 task JSON 会 `start_pick` / `complete_*`，但没有评分入口 `mission_client.py`。不要再写第二套任务状态机。

### 3.6 感知与控制的其它坑

- YOLO 必须 **CPU**（`CUDA_VISIBLE_DEVICES=`），否则和 Server GS 抢 4060
- 抓取 creep **不能**走 P4 雷达 `STOP_DIST=0.43`，否则顶住货架进不去
- 锁失败可拿 P3 槽位当**头部朝向提示**，禁止把 marker id / JSON 坐标当抓取 xyz
- 初版只认 `kind=kele`；任务是别的类直接失败

## 4. 九类物体尺寸（官方碰撞体）

来源：Server 镜像 `retail_competition.xml` 的 `product_*_collision`。  
MuJoCo：`cylinder size="半径 半高"`，`box size` 是**半边长**，`sphere size` 是半径。下表「外形」已换成全尺寸。

质量、摩擦与 XML 一致。外观是 3DGS ply；**抓放按碰撞体**，不要按 ply 包络猜。

| `kind` | 中文 | 碰撞类型 | 外形（m） | 质量 (kg) | 抓取含义 |
| --- | --- | --- | --- | --- | --- |
| `kele` | 可乐 | 直立圆柱 | 直径 **0.053**，高 **0.145** | 0.357 | 官方配方对象。表面→中心补 26.5 mm。`GRIP_CLOSE=0.08` |
| `maidong` | 脉动 | 直立圆柱 | 直径 **0.065**，高 **0.210** | 0.643 | 比可乐粗、高、重。同一 creep/闭合会偏。L2 中心 z≈0.956 |
| `shupian` | 薯片 | 直立圆柱 | 直径 **0.065**，高 **0.210** | 0.137 | 外形同脉动，轻很多。易碰倒 |
| `kouxiangtang` | 口香糖 | 直立圆柱 | 直径 **0.049**，高 **0.080** | 0.073 | 最矮的柱。多在 L3（中心 z≈1.229），现 `REACH_Z` 会滤掉 |
| `pingguo` | 苹果 | 球 | 直径 **0.070** | 0.251 | 无「前表面半径」可直接套可乐公式；要按球心抓 |
| `chengzi` | 橙子 | 球 | 直径 **0.074** | 0.253 | 同苹果，略大 |
| `zhijin` | 纸巾 | 盒 | **0.172 × 0.085 × 0.088** | 0.130 | 最宽。侧向抓还是沿短边，要单独定。L2 中心 z≈0.895 |
| `sanmingzhi` | 三明治 | mesh 楔包 | 约 **0.065 × 0.100 × 0.099** | 0.122 | 6 顶点薄包，不是圆柱。多在 L1（中心 z≈0.548） |
| `heweidao` | 核味道 | mesh 圆台 | 高 **0.105**；底半径 0.0325、顶半径 0.0475 | 0.099 | 上粗下细的罐。表面补半径不能只用一个数 |

固定布局对照：`TASKS=product_032` 是 D 架 L2 的可乐罐，碰撞 `cylinder size="0.0265 0.0725"`。

货架三层（物体**中心**高度，同 XML `pos`）：

| 层 | 中心 z（约） | 现 `REACH_Z` 0.70–1.15 |
| --- | --- | --- |
| L1 | 0.55–0.60 | 会丢 |
| L2 | 0.89–0.96 | 能进（可乐/脉动/纸巾） |
| L3 | 1.22–1.23 | 会丢（口香糖/水果） |

### 4.1 夹爪 / 手掌（MMK2 右臂，Airbot Play G2）

来源：Server `models/mjcf/mobile_chassis/mmk2/arm_right.xml`、`mmk2_options.xml`、`mmk2_control.xml`，以及 `airbot_play_dependencies.xml`。左右臂对称。末端是 **G2 平行双指**，不是灵巧手。

**开口（能握住多宽）**

| 量 | 值 | 说明 |
| --- | --- | --- |
| 指令范围 | `ctrlrange` **0～1** | ROS 话题里的 `*_eef_gripper_joint` |
| 单指行程 | **40 mm** | `finger` 滑动关节 `range` 0～0.04 m，左右镜像 |
| 两指内缘最大开口 | **80 mm** | 指令 `1.0`；腱轮 `coef=±12.5`，开口 ≈ `0.08 × 指令`（米） |
| 完全闭合 | **0 mm** | 指令 `0.0`，指面在中线碰上 |
| 官方可乐闭合 | 指令 **0.08** | 目标开口约 **6.4 mm**，小于罐径 53 mm，是挤紧而不是「张到罐径」 |
| 官方张开 | 指令 **1.0** | 80 mm，大于可乐/脉动/水果，小于纸巾盒 |

**手指垫（注释里的盒近似；正式碰撞是 mesh `left` / `right`）**

每根手指三块板，`box size` 是半边长：

| 段 | 全尺寸 | 在手指上的位置 |
| --- | --- | --- |
| 指尖 | **24 × 4 × 20 mm** | 最外侧 |
| 中段 | **24 × 4 × 40 mm** | 中间 |
| 指根 | **24 × 4 × 60 mm** | 靠近手腕 |

合在一起：

- 指长（伸进货架的方向）约 **72 mm**
- 指面厚度约 **4 mm**（每侧）
- 指面高度（抱住瓶身的上下方向）指尖 20 mm、指根 60 mm

**掌座 / 手腕壳体（link6 碰撞盒，在手指后面）**

`geom type="box" size="0.025 0.08 0.015"` → 全尺寸 **50 × 160 × 30 mm**，中心在 endpoint 后方约 70 mm。这是手掌本体，比指面宽，插货架时容易先碰到隔板。

**和 9 类能不能塞进 80 mm 开口**

| kind | 要夹的特征尺寸 | 相对 80 mm |
| --- | --- | --- |
| kele | ⌀53 mm | 能进；用 0.08 挤紧 |
| kouxiangtang | ⌀49 mm | 能进 |
| maidong / shupian | ⌀65 mm | 能进，余量约 15 mm |
| pingguo / chengzi | ⌀70 / 74 mm | 刚能进 |
| sanmingzhi | 最薄约 65 mm | 只能夹薄边 |
| heweidao | 底 ⌀65 mm，顶 ⌀95 mm | 只能抓下半；顶部超出开口 |
| zhijin | 85 / 88 / 172 mm 三条边 | **三条边都 ≥85 mm，轴对齐时夹不进** |

纸巾是最大风险：G2 最大开口 80 mm，盒碰撞从 85 mm 起。要么斜着/掐角，要么 mesh 比盒略软，不要假设能像可乐一样对心夹。

## 5. 裁判怎么判搬离 / 放置

`retail_referee_config.json`（已写入 `runtime/scene_zones.py`）：

| 项 | 值 | 对 P5 的含义 |
| --- | --- | --- |
| 时限 | 420 s 仿真钟 | 一次取送不能拖死 |
| 搬离 | 水平位移 ≥ 0.20 m | 夹住还贴在货位上不算取走 |
| 放置区 | `delivery_box` x∈[-2.42,-1.46] y∈[-3.63,-3.19] z∈[0.74, 1.05] | 导航目标仍是北侧接近点 `(-1.94, -2.90)`，不要开进桌肚 |
| 桌面目标 | `(-1.94, -3.41, 0.807)` | 放货 IK 目标，不是底盘目标 |
| 直立 | ≤15° 有加分；>30° 或水平移 >0.05 m 算倾倒 | 松爪高度、姿态要稳 |
| 掉落 | z 下降 ≥ 0.30 m | 去配送途中松爪会罚 |
| 碰撞 / 倾倒 / 掉落罚分 | 5 / 5 / 3 | 抓飞、撞架、路上掉都贵 |

作业规则仍是 **取一件立刻送一件**。失败不得重置 Server。

## 6. 建议怎么拆（待讨论，未批准）

下面只是讨论菜单。没点头不要按这个改代码。

### 6.1 先把可乐取送闭环做稳

1. 货架前抓（已有日志 `held`）→ 目视是否真夹住、有没有刮货架  
2. 倒车满足 0.20 m 搬离  
3. P4 送到配送接近点（手臂保持闭合）  
4. 放到 `delivery_box`，看裁判而不是 Client 的 `placed`  
5. 再接 `MissionOrchestrator` + `scripts/run_mission.sh`

不要并行开 Nav2 / DWA / 黄线 fallback。不要改 `client_task_1.py`。

### 6.2 几何改成 footprint，不要世界系 +Y

锁目标、展开点、creep 停止、倒车，都应在底盘 footprint（前向 / 左向 / 上）里算。世界系偏移只适合当前这组北向货架。

`kind` → `{radius_or_halfsize, height, grip_close, reach_z_band, grasp_rot}` 一张表。可乐用现成 26.5 mm / 0.08；其它类先占位，等 A 的权重。

### 6.3 层高与扫视

L1 / L3 必须能锁。头俯仰已有 `AISLE_SCAN_POSES` 和槽位 hint（L/C → yaw/pitch），但 `REACH_Z` 还卡在中层。讨论：按槽位层放宽 z，还是按检测高度分三段。

### 6.4 形状分组，不要 9 套手臂程序

| 组 | kind | 思路 |
| --- | --- | --- |
| 细高柱 | kele, kouxiangtang | 现可乐 creep；口香糖更矮、多在 L3 |
| 粗高柱 | maidong, shupian | 更大半径、更松闭合、脉动更重 |
| 球 | pingguo, chengzi | 球心，不要圆柱表面补偿 |
| 扁盒 | zhijin, sanmingzhi | 三明治只能夹薄边；纸巾三条边都 ≥85 mm，超过 80 mm 开口 |
| 圆台 | heweidao | 按中段半径，不要当可乐罐 |

双臂 hug、文旅站位不要用。初赛先右臂。

### 6.5 失败与重试

抓空：P3 绑槽 → 只改看的方向 → 再视觉锁。禁止 JSON 坐标。  
路上掉：记原因，从当前物理状态重观测，禁止重启容器。  
超时：`stop_all`。
